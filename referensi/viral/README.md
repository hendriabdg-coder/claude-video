# Referensi video viral (bahan belajar reviewer)

Taruh video contoh di:
- `motion/`: faceless motion graphic
- `hybrid/`: talking head + motion

Opsional, satu file `.txt` bernama sama dengan videonya, isinya link asli + views/like/komentar.

Dipakai HANYA untuk analisis pola (hook, tempo, ritme visual, struktur, gaya bahasa, pemicu komentar).
Jangan meniru visual atau isinya. Hasil bedah: `kartu/<nama>.md`, lalu diringkas ke `pola-viral.md`.
