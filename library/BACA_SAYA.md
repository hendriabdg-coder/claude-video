## talking-head\aset\broll\  — B-roll umum, dipakai ulang di banyak video
- Klip 3–10 detik, tanpa watermark, milikmu sendiri / bebas lisensi.
- Vertikal 1080x1920, atau horizontal 4K (akan di-crop ke 9:16 — taruh objek utama di tengah).
- Nama file = isi klip, contoh:
  broll_ketik-laptop_meja-malam.mp4
  broll_layar-coding_closeup.mp4
  broll_hp-scroll-chat-ai.mp4
  broll_papan-tulis_diagram.mp4
  (hindari IMG_2041.mp4 — Claude memilih klip dari namanya + 3 frame pratinjau)
