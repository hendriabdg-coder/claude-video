3 kesalahan yang bikin API key kamu bocor

1) Key ikut ke-commit ke GitHub. Walau sudah dihapus dari kode terbaru, key itu masih ada di riwayat. Jadi ganti (rotasi) key-nya, jangan cuma dihapus.
2) Key ditaruh di front-end. Key yang ada di kode website bisa terbaca lewat browser.
3) Key ikut terbagikan tanpa sadar: di screenshot, log error, atau saat paste kode ke AI coding.

Menurut GitGuardian (State of Secrets Sprawl 2026), ada 28,65 juta secret baru (API key, token, password) yang terdeteksi di commit GitHub publik sepanjang 2025.

Simpan secret key di back-end, batasi aksesnya, dan jangan dibagikan sembarangan.
