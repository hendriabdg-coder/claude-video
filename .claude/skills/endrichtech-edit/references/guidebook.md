# ENDRICHTECH VIDEO EDITING GUIDEBOOK — v1.0

> Written by the creator. Primary use: Claude Code / AI video editor. Format: short-form vertical video for TikTok,
> Instagram Reels, Facebook Reels, YouTube Shorts. Core identity: **Cinematic Editorial Tech Storytelling.**
>
> **Owner overrides (2026-10-06):** accent colors = approved yellow/red/green set; no subtitles — kinetic text covers
> ~70–80% of spoken beats; full-screen text cards rare; dramatic device = hybrid, one per video by theme; font = Inter
> Display (Apple-style). Concrete values live in `style-tokens.md`, which wins on any conflict with this file.

## 1. Purpose
This guidebook defines the visual language, editing logic, animation behavior, typography, pacing, B-roll usage,
evidence presentation, sound design and decision-making rules for EndrichTech video content. Treat it as the default
editing system, not optional inspiration. The goal is not the most visually complex video; it is a video that is
**clear, modern, human, intelligent, visually engaging and easy to follow.** Editing must support the story — never compete with it.

## 2. Core philosophy
Hierarchy: **Human → Story → Information → Visual Support → Decoration.** The creator is the anchor; the viewer should
feel one person is explaining something directly to them, not watching a corporate presentation.
Every visual element must answer at least one: Does it make the idea easier to understand? Strengthen emotional impact?
Provide evidence? Reset attention? Improve narrative progression? If no — do not add it.

## 3. Brand feel
Modern, clean, human, editorial, cinematic, technology-oriented, intelligent, minimal, premium without looking luxurious,
energetic without becoming chaotic. Should feel like *a technology creator who understands storytelling, design, business
and the internet.* NOT a generic TikTok template, NOT a corporate presentation, NOT a cyberpunk gaming montage, NOT an
over-edited motivational video.

## 4. Primary content modes (identify before editing)
- **Mode A — Story** (storytelling, opinion, business lessons, AI concepts, education, observations, commentary, analogies).
  Structure: Creator → Keyword → Supporting Visual → Creator. Talking head stays the anchor. Tools: keyword typography,
  subtle punch-in, B-roll, metaphorical visual, simple icons, clean diagrams, relevant screenshots, minimal motion graphic.
  Do not cover the creator continuously.
- **Mode B — Evidence** (AI/company news, research, benchmarks, statistics, announcements, controversial claims, quotes,
  reports, comparisons). Structure: Claim → Source → Evidence Highlight → Interpretation → Creator. Assets: article/website
  screenshot, paper, chart, benchmark, social post, statement, product page, document excerpt. Evidence is part of the
  story, highlight only the relevant portion, dim the rest, never force reading a whole article.
- **Mode C — Product/Tech** (AI tools, apps, websites, software, dashboards, automation, devices, workflows, tutorials, demos).
  Structure: Creator → Device/UI → Interaction → Result → Creator. Use screen recordings, UI zoom, device B-roll, cursor
  movement, UI highlight, feature callout, before/after. Keep interface footage clean and readable; avoid heavy graphics over UI.

## 5. Video format
9:16, 1080×1920 minimum, vertical, source frame rate (default 30 fps). Protect important content from platform UI: not
too close to top, bottom, right edge, or caption/interface zones. Keep breathing room.

## 6. Visual hierarchy
One dominant visual idea per scene. Priority: 1 creator face/primary subject, 2 main idea, 3 supporting text,
4 supporting visual, 5 decoration. When everything is emphasized, nothing is.

## 7. Talking head rules
The creator is home base. Return after evidence, B-roll, screen recording, diagram, motion graphic or metaphor. Don't stay
away too long unless the visual sequence itself progresses. Framing changes create rhythm (medium, medium close-up,
close-up, subtle crop, 45°, device detail, over-the-shoulder, top-down). No random zooming; camera changes follow narrative intensity.

## 8. Punch-in and digital zoom
Normal explanation: none or very subtle. Important statement: gentle punch-in. Strong conclusion: slightly stronger.
Question/tension: slow push-in. Humor/irony: optional quick crop change. Don't zoom in/out every sentence.
Range 100% → 105–112%; rare max 115–118%. Avoid extreme crops unless deliberate.

## 9. Typography system
Editorial, bold, readable, restrained: modern sans, medium-to-bold, high readability, clean geometry, strong hierarchy,
minimal decoration. Families: Inter, Geist, Manrope, Satoshi, Plus Jakarta Sans, DM Sans. Prefer one family; max 2.

## 10. Text hierarchy
- **L1 Hero keyword** — largest, bold, short, high contrast, 1–5 words (e.g. "MODEL PALING MAHAL").
- **L2 Supporting statement** — 1–2 short lines (e.g. "80% tugas sebenarnya tidak butuh model frontier.").
- **L3 Metadata** — source, company, date, category, small labels; visually quieter.

## 11. Keyword emphasis
Do NOT animate every spoken word; identify semantic keywords. VO "Masalahnya bukan AI-nya kurang pintar. Masalahnya semua
pekerjaan dikasih ke model yang sama." → "BUKAN AI-NYA", later "SATU MODEL / UNTUK SEMUA TUGAS". Text summarizes meaning,
it does not duplicate the VO.

## 12. Subtitle system
*(Overridden: no subtitles. Kinetic text takes over comprehension — see style-tokens.)* Original principles that still apply
to kinetic text: max 2 lines, short phrase grouping aligned to speech rhythm, readable duration, consistent baseline, never
block the face, little animation, emphasize only important words. Split long sentences into fragments
("Sistem AI modern…" / "bisa pakai model berbeda" / "untuk tugas yang berbeda.").

## 13. Text positioning
Default lower-middle within the safe zone, but react to composition: creator left → text/graphic right; creator right →
left; creator centered → keyword above or below the face. Don't center everything permanently; use negative space.

## 14. Editorial layout style
One idea + one visual + strong whitespace. Avoid five icons + four boxes + three arrows + paragraph + chart in one frame.
Reveal progressively: "100 TUGAS" → "80 → Small Model" → "15 → Medium Model" → "5 → Frontier Model".

## 15. Motion design principles
Smooth, controlled, purposeful, fast enough for short-form, not hyperactive. Preferred: fade, slide, mask reveal, scale,
position shift, opacity change, parallax, simple camera movement, directional motion. Avoid aggressive bounce, random
rotation, excessive elastic, chaotic glitch, unnecessary particles, meme transitions (unless requested).

## 16. Animation timing
Default 0.20–0.50 s; fast emphasis 0.15–0.30 s; editorial reveal 0.30–0.60 s; slow dramatic 0.6–1.5 s. Animation finishes
before the viewer gets impatient.

## 17. Easing
Ease-out for entrance, ease-in for exit, ease-in-out for camera/object movement. Linear only for progress, timelines,
loading, technical movement. Physically believable.

## 18. Scale animation
Entrance 95%→100% or 90%→100%. Strong emphasis 85%→105%→100%, sparingly. No exaggerated bouncing.

## 19. Text entrance
Fade upward, mask reveal, subtle slide, scale+opacity, word-group reveal. Example: opacity 0→100%, y 20–50 px → 0,
0.25–0.4 s. Never fly text across the frame.

## 20. Transition system
Default = hard cut; cuts carry most of the edit (~80–90%). Allowed when they connect ideas: match cut, whip, directional
slide, blur, object-based, light motion blur, seamless zoom, mask. Avoid spins, star wipes, random templates, colorful
wipes, cheesy zooms, a transition on every cut.

## 21. Editing rhythm
Meaningful visual change about every 1.5–3.5 s — not a strict timer; never cut just because 3 s passed. A change can be a
camera angle, crop, keyword, B-roll, screenshot, UI, graphic, diagram, animation, object, metaphor. Narrative rhythm beats
mechanical frequency.

## 22. Pattern interruption
Use when attention may drop, a section begins, a major claim appears, the topic turns, or surprising information arrives.
e.g. talking head → full-screen article → close-up → simple diagram → talking head. Reset attention without breaking coherence.

## 23. B-roll rules
Must have narrative value: show a product, demonstrate a workflow, a real example, establish environment, make an abstract
idea concrete, create contrast, hide necessary cuts. No irrelevant stock footage for a keyword. "Bisnis yang buruk biasanya
bukan kekurangan tools" → not businessmen typing; instead cluttered dashboard, redundant tools, many app windows, the creator
switching apps, duplicated workflow. Specific beats generic.

## 24. Visual metaphors
For abstract ideas, one simple metaphor per concept: too many tasks → overflowing inbox; AI routing → traffic intersection;
automation → conveyor belt; model selection → tool box; bottleneck → narrow pipe; information overload → stacked windows.

## 25. Screen recording
Crop aggressively to the relevant interface; use zoom, cursor focus, highlight, subtle dimming, bounding box, blur outside
focus. Intentional cursor movement. Show action → show result.

## 26. Evidence presentation
1 show publication/source identity, 2 establish what we're looking at, 3 zoom into the relevant sentence, 4 highlight only
the evidence, 5 keep attribution visible where practical, 6 return to the creator's interpretation. Never as decoration.

## 27. Article screenshot style
Clean crop, optional slight perspective and soft shadow, irrelevant area dimmed, relevant phrase highlighted, publication
name/logo visible when useful. Prefer elegant underline, translucent highlight, soft rectangle, controlled zoom over big red circles.

## 28. Charts and data
A chart answers one question. Simplify (80% small / 15% medium / 5% frontier instead of a 12-series chart), animate
sequentially, numbers visually dominant.

## 29. Icons
Simple, consistent, geometric, modern, high contrast. One system — don't mix 3D, flat, emoji and hand-drawn. Secondary support only.

## 30. Graphic cards
For concepts, categories, comparisons, workflow, data, UI abstractions: clean, moderate radius, subtle border and shadow,
neutral background, restrained accent. Never generic Canva templates.

## 31. Color system
*(Accent set overridden — see style-tokens.)* Neutral, modern, cinematic base: black, near-black, dark gray, white,
off-white, neutral gray. Accents from EndrichTech identity, product branding, evidence source or semantic meaning. No rainbow palettes.

## 32. Color grading
Natural skin; moderate contrast, controlled highlights, clean blacks, restrained saturation, subtle cinematic feel. Not
excessively teal-orange, blue, desaturated, dark or HDR. Clarity beats drama.

## 33. Background
Supports creator identity: developer workspace, desk setup, tech environment, clean room, practical lights, depth. No fake
futuristic environments unless the story needs it — *real technology being built by a real person.*

## 34. Sound design
Strengthens actions without being noticed: subtle whoosh, click, tap, UI tick, soft impact, sweep, digital confirmation,
gentle riser, low hit, keyboard/device sounds. No cartoon sounds unless comedic.

## 35. SFX logic
SFX may accompany text appearance, important number, card entrance, UI selection, major transition, evidence highlight,
payoff, CTA. Not every animation needs sound — when everything sounds, nothing matters.

## 36. Music
Supports mood, never fights the voice: low-volume electronic, minimal beats, subtle ambient tech, restrained cinematic pulse,
light rhythm. No epic music for normal explanations.

## 37. Audio hierarchy
Voice > important SFX > music > ambience. Speech stays clear (compression/loudness balancing as needed); music dips during
important statements.

## 38. Hook editing
First seconds establish tension, curiosity, contradiction, a surprising idea, a recognizable problem or an unusual question.
No branding animation, no logo, no long establishing shot — start with the idea. Hook visuals: creator close-up, strong
keyword, surprising B-roll, contradiction graphic, headline, question, comparison.

## 39. First 3 seconds
0.0–1.0 s human or strong visual; 1.0–2.0 s main hook information; 2.0–3.0 s reinforcement or pattern shift. Viewer gets the
topic fast without the whole answer.

## 40. CTA treatment
A continuation of the conversation, not an ad: talking head + minimal text (e.g. "MUNGKIN MASALAHNYA / ADA DI SISTEM.").
Small branding allowed. Don't overload with logo, phone, website, QR, five icons, follow button, three animations. One action.

## 41. Branding
Subtle: small watermark, restrained logo, occasional name, end-card only when useful. Recognition comes from consistency.

## 42. Information density
Don't show everything the VO says. Visuals summarize, visualize, demonstrate or prove. If the VO is already clear, stay on
the creator. Silence and empty space are allowed.

## 43. Human-first rule
Between a flashy animation and a clear human reaction/gesture/expression/camera moment, prefer the human moment when it
carries the story better.

## 44. Editing decision engine
Strong opinion → creator + punch-in + keyword (don't jump to B-roll). Number → animated number/simple data visual. Claim →
source/evidence. Software → actual interface. Action → demonstration or contextual B-roll. Abstract system → simple diagram
or metaphor. Emotional/personal reflection → creator, fewer graphics. Punchline/payoff → creator or strongest visual.
Nothing adds value → stay on the creator; don't invent visual noise.

## 45. Scene selection logic
Classify every sentence: **A Human** (expression/direct delivery), **B Concept** (typography/diagram), **C Evidence**
(article/source/data), **D Demonstration** (UI/product/B-roll), **E Transition** (visual reset). Choose visuals accordingly.

## 46. Visual priority matrix
Personal statement → creator · Question → creator/keyword · Important phrase → typography · Statistic → number visual ·
Research claim → evidence · Software feature → screen recording · Physical product → product B-roll · Abstract
explanation → diagram · Comparison → split layout/cards · Process → sequential visual · Emotional conclusion → creator.

## 47. Cutting speech
Remove unnecessary silence, repeated phrases, obvious hesitation, dead air, accidental pauses — but keep natural breathing so
speech doesn't become robotic. Keep conversational rhythm.

## 48. Jump cuts
Acceptable. Hide disruptive ones with crop change, angle change, B-roll, text, screenshot or punch-in — not every one;
visible jump cuts are normal in short-form.

## 49. Pacing by section
Hook: fast, change every ~0.8–2 s. Explanation: ~1.5–3.5 s per visual state. Important concept: slow down. Evidence: enough
time to read the highlight. Payoff: reduce distraction, let it land. CTA: simple, human, clear.

## 50. Retention strategy
From unanswered questions, narrative progression, useful information, perspective changes, visual proof, escalating insight,
pattern interruption — not endless stimulation. Attention ≠ sensory overload.

## 51. Before/after
Split screen, swipe reveal, alternating cut or side-by-side cards; label BEFORE/AFTER clearly; no complicated transitions.

## 52. UI motion graphics
Fictional/explanatory UI stays realistic: subtle shadows, restrained blur, clean cards, realistic spacing, readable type,
limited accent. No sci-fi HUD unless the context demands it.

## 53. Animation layer limit
Per scene: 1 primary motion event + 1 secondary. Never headline + icon + background + border + particles + camera at once.

## 54. Text length limit
Hero 1–5 words; supporting ~5–12 words. Long explanations stay in the VO. Never a paragraph over talking-head footage.

## 55. Full-screen text
Only for a major question, chapter transition, dramatic statement, important number, contradiction or payoff — rare enough to matter.

## 56. Depth
Foreground element, creator, background, shallow depth of field, subtle overlay layers, parallax. Avoid flat compositions
when footage allows depth.

## 57. Masking and cutouts
Creator cutouts for diagrams, UI interaction, comparing objects, data around the creator — not overused; normal footage stays primary.

## 58. Motion blur
Subtle, during fast slides, whips, rapid scale, camera movement. Not on static elements.

## 59. Background graphics
Subtle: gradient movement, faint grid, blurred light, soft parallax, very subtle noise. Never compete with the foreground.

## 60. Texture
Slight editorial texture is fine (soft grain, subtle noise, faint paper in editorial sections), barely noticeable. No vintage
film look unless requested.

## 61. Source attribution
For external claims show publication, organization, author/date when relevant, headline, quoted section. Never fabricate source graphics.

## 62. Cropping evidence
Hierarchy: logo → headline → highlighted evidence. Remove navigation, ads, blank space, unrelated paragraphs, but keep enough
context so it doesn't feel manipulated.

## 63. Screenshot animation
Full source → slow push → relevant section → highlight → hold → cut back to creator. Don't zoom into text before showing where it came from.

## 64. Numeric animation
Count-up, bar growth, card reveal, sequential appearance; fast. 80% → then 15% → then 5%, not all at once.

## 65. Visual progression
Each visual reveals something new. Bad: creator → crop → crop → crop. Better: creator → keyword → simple graphic → example → creator conclusion.

## 66. Continuity
Consistent typography, color, spacing, motion behavior, graphic language — no new aesthetic halfway through.

## 67. Do not over-template
Vary composition, framing, B-roll, evidence treatment, metaphors, shot sequence. Keep philosophy, typography, motion
behavior, color discipline and pacing consistent.

## 68. Do
Prioritize clarity · preserve creator personality · visual storytelling · emphasize important words · show evidence when
claims need it · real interface footage where possible · clean motion · cinematic framing · negative space · confident hard
cuts · intentional visual changes · simplify complex info · create progression · return regularly to the creator.

## 69. Do not
Animate every sentence · subtitle every word individually · irrelevant stock footage · random glitch · excessive neon ·
cyberpunk by default · overuse zoom · bounce every element · a transition on every cut · five colors at once · fill every
empty space · cover the creator's face · unreadable charts · tiny evidence · music over VO · graphics only because the frame
looks empty · generic Canva compositions · turn informational videos into ads.

## 70. Fallback rules
No B-roll → creator + typography + crop variation (not unrelated stock). Poor evidence screenshot → clean recreated text with
explicit source attribution; never fabricate evidence. No UI footage → simplified conceptual interface, labeled when
necessary. Scene feels empty → first try crop, framing, gesture, typography before decoration. VO too dense → reduce visual
complexity; don't visualize every noun.

## 71. Claude editing workflow
1 Understand the script (hook, tension, key claim, explanation, evidence, examples, payoff, CTA) · 2 Segment VO into
semantic beats (not by punctuation) · 3 Classify each beat (Human/Concept/Evidence/Demonstration/Transition) · 4 Assign
treatment (talking head, typography, B-roll, UI, source, chart, diagram, metaphor) · 5 Rough cut: story, pacing, clarity
only · 6 Supporting visuals only where they improve comprehension/retention · 7 Typography: keywords, numbers, key concepts
· 8 Restrained motion · 9 Sound design synced to key moments · 10 QA against this guidebook.

## 72. Decision rule
When uncertain: **Clarity > Story > Human Presence > Evidence > Visual Interest > Decoration.** Never reverse it.

## 73. Editing intensity (adjust per section)
1 Minimal — talking head, subtle crop (emotional moment, serious statement, CTA, reflection). 2 Standard — talking head +
keywords + occasional visual (default). 3 Dynamic — frequent change, graphics, evidence (hook, demo, dense sequences).
4 High energy — fast progression, rare (major reveal, fast comparison, montage). Never level 4 for the whole video.

## 74. Default end-to-end pattern (guideline, not template)
Hook: creator + strong keyword → Problem: creator + relatable visual → Reframe: punch-in + typography → Explanation:
graphic/UI/diagram → Evidence: source or example → Interpretation: creator → Payoff: minimal visual → CTA: creator + short text.

## 75. One-to-one communication
Preserve the feeling that the creator talks to one person: eye contact, close framing, controlled pacing, conversational
pauses, reaction shots, human gestures. Graphics appear to help explain to the viewer personally.

## 76. Narrative-first rule
Before adding anything ask: "What does the viewer need to understand or feel at this exact moment?" Never start from "what
effect can I add here?"

## 77. End result
*Someone smart is explaining something interesting directly to me, and the editing quietly helps me understand it.* Not:
someone is trying to impress me with editing.

## 78. Final quality-control checklist
- **Story:** hook immediately understandable; narrative progresses naturally; payoff earned; CTA matches the story.
- **Creator:** face stays important; natural gestures preserved; talking-head shots never static too long.
- **Typography:** readable; keywords selective; no paragraphs; clear hierarchy.
- **Visuals:** B-roll relevant; evidence legible; UI cropped; metaphors understandable.
- **Motion:** purposeful; no excessive bounce; no random effects; hard cuts dominant.
- **Pacing:** no long dead sections; no sensory overload; important ideas get enough screen time.
- **Sound:** voice clear; music secondary; SFX only on meaningful moments.
- **Branding:** consistent style; restrained branding; still feels human.

## 79. Master instruction
Follow this guidebook as the default creative and technical standard. Don't maximize effects — maximize clarity, narrative
progression, retention, visual comprehension and human connection. The creator is the primary visual anchor. Add B-roll,
typography, screenshots, data, motion graphics, UI footage and sound only when they support the meaning of the spoken
content. Default aesthetic: Cinematic Editorial Tech Storytelling. Philosophy: human first, story second, visual support
third, decoration last. If uncertain between two choices, pick the simpler one that communicates more clearly. The output
must feel deliberate, modern, premium, intelligent and human.
